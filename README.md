# 🤖 Bybit Monitor Bot

Телеграм-бот для мониторинга ценовых уровней на Bybit с уведомлениями в реальном времени и базовым техническим анализом.

## ✨ Возможности

- 📊 **Мониторинг ценовых уровней**  
  Отслеживание пересечений (снизу вверх / сверху вниз / любое направление).

- 🧠 **Умная фильтрация алертов**  
  Оценка сигнала по паттернам (пин-бар, поглощение), объёму, тени, закрытию свечи, RSI и тренду на 4H. Слабые сигналы отфильтровываются.

- ⏳ **Кулдаун алертов**  
  Защита от повторных уведомлений по одному и тому же уровню.

- 🔍 **Скринер рынка**  
  Поиск монет с сильным движением цены за 24ч (фильтр по объёму и изменению).

- 💬 **Управление через Telegram**  
  Добавление, удаление и просмотр алертов прямо в боте.

- 📝 **Заметки к уровням**  
  Можно сохранять сетап/комментарий к каждому алерту.

- 🚀 **Массовое добавление**  
  Можно отправить сразу несколько алертов одним сообщением.

- 💰 **Текущие цены**  
  Быстрый просмотр актуальных цен всех отслеживаемых активов.

- 📊 **Выгрузка данных**  
  Экспорт свечей (15m / 1H / 4H) + RSI в CSV по одному или нескольким тикерам.

## 🛠 Установка

### 1. Клонирование

```bash
git clone https://github.com/andrZUEV/bybit_monitor_bot.git
cd bybit_monitor_bot
```

### 2. виртуальное окружение

python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

### 3. Установка зависимостей

pip install -r requirements.txt

### 4. Настройка .env

cp .env.example .env

Открой .env и заполни:
# Telegram
TELEGRAM_BOT_TOKEN=123456:ABC-DEF...          # токен от @BotFather
TELEGRAM_CHAT_ID=328515075                    # твой chat_id

# Мониторинг
POLL_INTERVAL=4                               # интервал опроса (сек)
VOLUME_THRESHOLD=5.0
VOLUME_COOLDOWN=300

# Анализ свечей
CANDLE_INTERVAL=15
CANDLE_PERIODS=20
CANDLE_VOLUME_MULTIPLIER=3.0

# Кулдаун алертов (минуты)
ALERT_COOLDOWN_MINUTES=15

# Логирование
LOG_LEVEL=INFO

Как узнать TELEGRAM_CHAT_ID

Напиши боту @userinfobot или @getmyid_bot.

### 5. Запуск

python main.py

После запуска бот отправит приветственное сообщение с меню.

📱 Меню бота

Кнопка,Что делает
➕ Добавить алерт,Пошаговое добавление уровня
🔍 Скринер,Топ монет по движению цены за 24ч
💰 Текущие цены,Актуальные цены всех отслеживаемых тикеров
📋 Мои алерты,Список алертов + удаление
📊 Выгрузить данные,Экспорт свечей + RSI в CSV
ℹ️ Помощь,Краткая справка


➕ Формат добавления алертов
Один алерт
SOLUSDT 118.5 up отбой от поддержки

или просто:

BTCUSDT 95000 down

Массовое добавление
Можно отправить несколько строк:

SOLUSDT 118.00 up отбой от поддержки
SOLUSDT 117.50 up отбой от поддержки
SOLUSDT 117.00 down пробой поддержки
SOLUSDT 119.80 down ретест сопротивления

Направления:

up — пересечение снизу вверх
down — пересечение сверху вниз
any — любое пересечение

⚙️ Важные замечания

Бот работает только с указанным TELEGRAM_CHAT_ID (защита от посторонних).
Для рыночных данных API-ключи Bybit не нужны (используются публичные эндпоинты).
Алерты и кулдауны сохраняются в data/.
При большом количестве тикеров рекомендуется увеличить POLL_INTERVAL, чтобы не упираться в rate-limit.

# Если запущен через systemctl
