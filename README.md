# 🤖 Bybit Monitor Bot

Телеграм-бот для мониторинга цен и объемов на Bybit с уведомлениями в реальном времени.

## ✨ Возможности

- 📊 **Мониторинг цен**: отслеживание пересечения ценовых уровней (снизу вверх / сверху вниз / любое)
- 📈 **Мониторинг объемов**: алерты при резком изменении 24h объема
- 🔍 **Скринер рынка**: поиск монет с сильным движением цены
- 💬 **Управление через Telegram**: добавление/удаление алертов через бота
- 📝 **Заметки к алертам**: запоминайте сетап для каждого уровня
- 🚀 **Массовое добавление**: отправьте список алертов одним сообщением
- 💰 **Текущие цены**: быстрый просмотр цен всех отслеживаемых активов
